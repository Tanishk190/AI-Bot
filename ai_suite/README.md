# AI Suite

Flask UI shell for a document intelligence app with five tools:

- AI Chat
- OCR
- PII Extractor
- Sentiment Analysis
- Document Classifier

## Run

```bash
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

The current version focuses on the UI and interaction layout. Core OpenAI, RAG, OCR, upload handling, and export logic will be connected next.
